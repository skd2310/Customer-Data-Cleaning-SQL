# Customer Data Cleaning — MySQL

## Project Overview

This project focuses on cleaning and standardizing customer data using MySQL.

## Objectives

- Remove extra spaces from customer names, emails, and cities
- Standardize customer names and emails
- Standardize city names
- Identify duplicate records
- Check for missing values
- Check for invalid email records
- Create a cleaned customer table

## SQL Concepts Used

- TRIM()
- LOWER()
- UPPER()
- COUNT()
- GROUP BY
- HAVING
- LIKE
- IS NULL

## Dataset

The dataset contains customer information including:

- Customer ID
- Customer Name
- Email
- City

## Result

The raw customer data was cleaned and standardized, and the final cleaned data was stored in the `customers_cleaned` table.
